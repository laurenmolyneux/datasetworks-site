Get the full product catalog of any Shopify store, with prices, sale prices, stock and variants, in one clean table.

Give it store domains. It reads each store's public product catalog and returns every product with the same fields every time. Ideal for price monitoring, competitor and market research, and feeding AI shopping or research agents.

Sample output

store title vendor priceMin priceMax currency onSale available variantCount
allbirds.com Women's Wool Cruiser - Port (Port Sole) Allbirds 120 120 USD false true 13

Each product also has productId, url, handle, productType, tags, compareAtPriceMax, imageUrl, imageCount, createdAt, publishedAt, updatedAt, scrapedAt and a variants list (id, title, SKU, price, compare-at price, availability).

How to use

  1. Add store domains to Stores, e.g. allbirds.com.
  2. Optional: Keywords to filter by title, type or tags; Max products per store.
  3. Tick One row per variant for a row per size/colour with its own price, SKU and stock (best for price tracking in spreadsheets).
  4. Run, or schedule daily to track price changes and new products.

A SUMMARY record lists how many products each store returned. Stores that don't publish a public catalog are listed with the reason and not charged.

Pricing

$0.80 per 1,000 products ($0.0008 per result). Stores with no public catalog are free. Platform usage is included.

For AI agents

Call it via the Apify API or MCP server with {"stores": ["allbirds.com"], "keyword": "runner", "maxProductsPerStore": 50}. Results have fixed fields, so agents can compare prices across stores directly.

Data and responsibility

The tool reads only the product catalog that Shopify stores publish openly at /products.json. It collects product and price data only: no customer, order or personal data. It follows each store's robots.txt and crawl delays, and skips stores that restrict access rather than getting around it.
