How to use

  1. Add companies to Companies. Any of these work:
  2. a board name: stripe
  3. a board name with a platform: lever:palantir, ashby:ramp, greenhouse:airbnb, personio:personio, recruitee:bunq
  4. a job-board link: https://jobs.lever.co/palantir, https://jobs.ashbyhq.com/ramp, https://boards.greenhouse.io/stripe, https://bunq.recruitee.com
  5. Optional filters: Title keywords (comma-separated, e.g. engineer, data), Remote jobs only, Max jobs per company.
  6. Tick Include full job description if you want the text of each posting.
  7. Run. Results appear in the dataset; export to CSV, Excel or JSON, or read them via the API.

The default input works with no setup. A SUMMARY record in the key-value store lists how many jobs each company returned, and which companies had no board found.

Tip: the board name is the last part of a company's careers link, e.g. jobs.lever.co/palantir.

FAQ

Is this a Greenhouse API or Lever API scraper? Yes. It reads the public job-board APIs of Greenhouse, Lever, Ashby, Personio and Recruitee and gives you one table with the same columns for all five, so you don't need separate code for each.

How do I find a company's board name? It's the last part of their careers link, e.g. boards.greenhouse.io/stripe or jobs.ashbyhq.com/ramp. If you only give a name, the tool tries each platform for you.

Does it work for LinkedIn or Indeed? No. It only reads companies' own public job boards, which are the original source of most tech and startup jobs, and it never logs in anywhere.

How do I track hiring changes over time? Save your company list as a task, schedule it daily or weekly, and send results to Google Sheets or a webhook. Each job has a stable jobId, so new and removed roles are easy to spot.

Can I use it with ChatGPT, Claude or Cursor? Yes. Add the Apify MCP server with this tool (https://mcp.apify.com/?tools=datasetworks/company-jobs) and ask "what data roles is Ramp hiring for?".

Data and responsibility

Data comes only from the public job-board APIs that Greenhouse, Lever, Ashby, Personio and Recruitee provide so companies can publish their jobs. The tool collects job postings, not people: no candidate or employee data, no logins, nothing behind access controls. It follows each site's robots.txt and rate limits.
