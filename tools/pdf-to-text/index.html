PDF to Text for AI: Extract Text from PDF URLs

Extract clean text from PDF files at public URLs, with page count, title, dates, per-page text and RAG-ready chunks. Fast, no browser, respects robots.txt.

Try it on Apify $3.00 per 1,000 pdf extracteds

Turn PDF files at public URLs into clean text, ready for an LLM, a RAG pipeline or an AI agent.

Give it links to PDFs (reports, filings, papers, manuals, tender documents, price lists). It downloads each file, reads its text layer and returns clean text plus page count, title, subject and dates. Optional per-page text lets you cite page numbers, and optional chunks drop straight into a vector database. No browser, so results come back in seconds.

Sample output

url title pageCount wordCount text (start)
https://www.irs.gov/pub/irs-pdf/fw9.pdf Form W-9 (Rev. March 2024) 6 6,306 Form W-9 (Rev. March 2024) Request for Taxpayer Identification Number and Certification ...

Each result also has status, finalUrl, httpStatus, subject, language, createdAt, modifiedAt, pagesExtracted, fileSizeBytes, charCount, hasTextLayer, truncated, fetchedAt and, if you ask for them, pages (text per page) and chunks (RAG-ready pieces).

How to use

  1. Paste one or more PDF links into PDF URLs.
  2. Optional: turn on Include text per page, set a Chunk size for RAG, or limit Max pages per PDF and Max characters per PDF to fit a model's context window.
  3. Run, then export as JSON, CSV or Excel, or read results via the API.

Files that can't be read are listed with status: "failed" or "skipped" and a reason, and are not charged.

For AI agents

Call it through the Apify API or the Apify MCP server with {"startUrls": [{"url": "https://example.com/report.pdf"}], "maxCharsPerPdf": 30000} and read text from the result. Every result has the same fields, and errors come back as data rather than crashes, so agents can handle them. Pair it with Web Page to Markdown & Clean Text for AI for HTML pages.

Limits

This tool reads the text layer inside the PDF. Scanned or image-only PDFs have no text layer: they come back with hasTextLayer: false and a note (OCR is not included). Password-protected PDFs, files behind a login and files over the size limit are skipped. Sites whose robots.txt disallows automated access are skipped.

Data and responsibility

The tool fetches only public files, identifies itself honestly as DatasetWorksBot, follows robots.txt and crawl delays, and never logs in or gets around captchas or blocks. It does not return the PDF's author field. You are responsible for how you use the content you extract, including copyright and any personal data in the files you choose.
