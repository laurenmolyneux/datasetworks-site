Turn PDF, Word, PowerPoint, Excel, OpenDocument and EPUB files at public URLs into clean text, ready for an LLM, a RAG pipeline or an AI agent.

Give it links to documents (reports, filings, papers, manuals, tender packs, slide decks, price lists, spreadsheets, e-books). It downloads each file, detects the format from the file itself and returns clean text plus title, subject, dates and page, slide or sheet count. Optional per-page text lets you cite a page, slide or sheet, and optional chunks drop straight into a vector database. No browser, so results come back in seconds.

Supported formats

Format What you get
PDF Text layer, page by page
Word .docx, OpenDocument .odt Paragraphs, tables as tab-separated rows
PowerPoint .pptx, OpenDocument .odp Text per slide, plus speaker notes (PPTX)
Excel .xlsx, OpenDocument .ods Each sheet as tab-separated rows under a ## Sheet name heading
EPUB Text per chapter, in reading order

Each result has a format field. Old binary .doc, .xls and .ppt files are not supported and are not charged.

Each result also has status, format, pageUnit (slide, sheet or chapter for non-PDF files), finalUrl, httpStatus, subject, language, createdAt, modifiedAt, pagesExtracted, fileSizeBytes, charCount, hasTextLayer, truncated, fetchedAt and, if you ask for them, pages (text per page) and chunks (RAG-ready pieces).

How to use

  1. Paste one or more file links into Document URLs.
  2. Optional: turn on Include text per page / slide / sheet, set a Chunk size for RAG, or limit Max pages per file and Max characters per file to fit a model's context window.
  3. Run, then export as JSON, CSV or Excel, or read results via the API.

Files that can't be read are listed with status: "failed" or "skipped" and a reason, and are not charged.

Limits

This tool reads text stored in the file. For PDFs that is the text layer. Scanned or image-only PDFs have no text layer: they come back with hasTextLayer: false and a note (OCR is not included). Password-protected or encrypted files, images inside documents, formulas (spreadsheets return the last saved values), files behind a login and files over the size limit are skipped. Sites whose robots.txt disallows automated access are skipped.

Data and responsibility
