Check DNS records, SSL certificate expiry, email provider, SPF and DMARC for a whole list of domains, in one clean row per domain.

Give it domains or URLs. For each one it returns the DNS records (A, AAAA, CNAME, MX, NS, TXT, SOA, CAA), who hosts the domain's DNS and email, its SPF and DMARC setup, and its SSL certificate (issuer, expiry date, days left, names covered, TLS version). Domains that don't exist in DNS are flagged as likely unregistered.

Sample output

Each row also has ipv4, ipv6, cname, mx (priority and host), nameservers, txt, soa, caa, spf, spfAll (fail / softfail / neutral), hasDmarc, dmarcSubdomainPolicy, dmarcPct, verifications (services the domain is verified with, e.g. google, facebook, apple), resolves, likelyUnregistered, sslValid, sslError, sslValidFrom, sslValidTo, sslNames, sslKeyBits, sslFingerprint256, tlsVersion and checkedAt.

How to use

  1. Paste domains into Domains, e.g. stripe.com (full URLs work too).
  2. Run. Export as CSV, Excel or JSON, or call it via the API. Schedule it daily to catch expiring certificates or DNS changes.

Use cases

  • SSL expiry monitoring: list every certificate expiring in the next 30 days across your sites or clients.
  • Email deliverability and security audits: find domains with no DMARC, a weak p=none policy or a missing SPF record.
  • Sales prospecting: segment leads by email provider (Google Workspace vs Microsoft 365) or DNS/CDN provider.
  • Domain portfolio checks: see which names don't resolve or look unregistered.
  • AI agents: give an agent fast, structured facts about a domain's infrastructure.

For AI agents

Call it via the Apify API or MCP server with {"domains": ["example.com"]}. You get one object per domain with fixed field names; status is ok, not-found (no DNS, likely unregistered) or failed with an error. Set checkSsl or checkDns to false to skip a part.

Data and responsibility

DNS answers come from public resolvers (Cloudflare and Quad9). The SSL check makes one normal TLS connection to port 443, as a browser would. The tool does not query WHOIS or RDAP registries and does not return personal data: the SOA contact mailbox, DMARC report addresses and CAA contact records are left out. "Likely unregistered" is based on DNS only, so confirm with a registrar before buying a name.
