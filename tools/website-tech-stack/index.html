How to use

  1. Paste domains into Websites, e.g. stripe.com.
  2. Run. Export as CSV, Excel or JSON, or call it via the API.

Use cases

  • Sales prospecting: find every Shopify or HubSpot site in your lead list, or companies without analytics.
  • Lead enrichment: add a description, logo and social links to a list of company domains.
  • Competitor and market research: see which tools a market uses.
  • AI agents: give an agent quick, structured facts about a company from its domain.

Pricing

$2 per 1,000 websites ($0.002 per website analysed). Websites that are unreachable or block automated access are free. Platform usage is included.

For AI agents

Call it via the Apify API or MCP server with {"domains": ["example.com"]}. One object per domain with fixed fields; failures come back as status: "failed" or "skipped" with a reason.

Data and responsibility

The tool loads each site's public homepage once, identifying itself as DatasetWorksBot, and follows robots.txt. It records company-level facts only: no personal names, emails or phone numbers. Social links are the company's own official profiles. Detection is based on public signatures in the page and response headers, so it can miss tools that load only after JavaScript runs.
