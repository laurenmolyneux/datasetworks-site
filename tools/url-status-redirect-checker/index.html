Check thousands of URLs for HTTP status codes, full redirect chains, loops, broken links, response times and security headers, in one clean row per URL.

Paste a list of URLs (or bare domains). For each one the tool follows every redirect hop and tells you where it ends up, which status code it returns, how long it took, the page title, and which security headers the final page sends. Short links (bit.ly and the like) are expanded to their real destination.

Sample output

url category statusCode finalUrl redirectCount securityHeadersScore
http://apify.com/ ok 200 https://apify.com/ 1 4
https://httpbin.org/redirect/3 ok 200 https://httpbin.org/get 3 1
https://httpbin.org/status/404 client-error 404 https://httpbin.org/status/404 0 1
https://nonexistent-domain-dw-test-xyz.com/ unreachable 0

Each row also has ok, redirectChain (every hop with its status code, location and time), redirectLoop, tooManyRedirects, httpsUpgrade (http was redirected to https), finalIsHttps, crossDomainRedirect, responseTimeMs, totalTimeMs, contentType, contentLength, title, server, lastModified, xRobotsTag, canonicalHeader, securityHeaders (HSTS, CSP, X-Frame-Options, X-Content-Type-Options, Referrer-Policy, Permissions-Policy), error and checkedAt.

category is one of ok, redirect (3xx when not following redirects), client-error (4xx), server-error (5xx), redirect-loop, too-many-redirects, redirect-error, timeout, ssl-error, unreachable (e.g. the domain doesn't resolve), stopped (a redirect pointed to a page that robots.txt blocks), skipped (blocked by robots.txt) or invalid.

How to use

  1. Paste URLs into URLs, one per line (up to 20,000 per run).
  2. Optional: turn off Follow redirects to see only the first response, or pick HEAD for a faster headers-only check.
  3. Run, then export as CSV, Excel or JSON, or call it from the API. Schedule it to catch links that break.

Use cases

  • Site migrations and SEO: confirm every old URL 301s to the right new page in one hop, with no chains or loops.
  • Broken link checks: find 404s and dead domains in a list of outbound links, backlinks or a CMS export.
  • Short link expansion: see where bit.ly and other short links really lead before you use them.
  • Security header audits: spot sites missing HSTS, CSP or X-Frame-Options.
  • AI agents: let an agent check whether a link is alive and where it goes, before it cites or fetches it.

For AI agents

Call it via the Apify API or MCP server with {"urls": ["https://example.com"]}. You get one object per URL with fixed field names. Use category and ok to branch, finalUrl for the real destination and redirectChain for the hops.

Data and responsibility

The tool only requests the URLs you give it, plus each site's robots.txt. It identifies itself honestly as DatasetWorksBot, respects robots.txt (a blocked URL is reported as skipped and not requested) and its crawl delay, and sends at most one request at a time to each site. It never logs in or bypasses captchas or blocks: a 403 or 429 is reported as it is. It reads at most 128 KB of each page, only to find the title, and returns no personal data.
