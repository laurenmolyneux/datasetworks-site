Paste page URLs (or bare domains). For each page the tool returns every schema.org item it finds (Product, Recipe, Organization, FAQPage, Article, Event, BreadcrumbList and more), the Open Graph and Twitter Card tags, the canonical URL, language, favicon, RSS feeds and hreflang links, and a linkPreview object with the title, description, image and site name you would show in a chat or CMS card.

How to use

  1. Paste URLs into URLs, one per line (up to 20,000 per run).
  2. Optional: switch off JSON-LD or microdata if you only need meta tags and the link preview.
  3. Run, then export as JSON, CSV or Excel, or call it from the API or MCP.

Use cases

  • SEO audits: check which pages have valid schema.org markup (Product, FAQ, Breadcrumb, Recipe) and Open Graph tags, and which have JSON-LD that fails to parse.
  • Product and price data: read Product and Offer data (name, SKU, price, currency, availability) that shops publish for search engines.
  • Link previews: build preview cards for chat apps, newsletters or CMS link fields.
  • Competitor monitoring: track how competitors mark up their pages and when it changes.
  • AI agents and RAG: give an agent the structured facts of a page (type, name, price, dates, ratings) without parsing HTML.

Privacy and fair use

Public pages only. robots.txt is respected (including crawl-delay), each site gets one request at a time, and sites that refuse automated requests (403/429) are reported, never bypassed. No logins or captchas. To keep personal data out, schema.org Person items and person fields such as author, creator, founder, employee and review are removed, along with author meta tags; personalDataFieldsRemoved counts what was dropped.
