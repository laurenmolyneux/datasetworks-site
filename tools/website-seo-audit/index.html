Crawl any website and get a page-by-page SEO audit in one clean table: broken links, titles, meta descriptions, H1s, canonicals, noindex, redirects, sitemap coverage, missing alt text, thin content and slow pages.

Give it one or more websites. It reads the site's robots.txt and XML sitemap, crawls up to your page limit, checks every link it finds, and returns one row per page with the measurements and a plain list of issues.

Each row also has finalUrl, redirected, responseMs, contentType, title, metaDescription, h1, h2Count, canonical, metaRobots, xRobotsTag, lang, hasViewport, ogTitle, ogImage, hreflang, structuredDataTypes (JSON-LD types), imagesTotal, imagesMissingAlt, wordCount, internalLinks, externalLinks, nofollowLinks, brokenLinks (URL, status, internal or external), unverifiedLinkCount, inSitemap, depth and auditedAt.

How to use

  1. Add websites, e.g. example.com or https://example.com/blog/.
  2. Set Max pages per site (default 25).
  3. Run, then export as CSV, Excel or JSON, or call it via the API. Sort by issueCount to see the worst pages first.

Data and responsibility

The tool identifies itself as DatasetWorksBot, follows robots.txt (including crawl-delay), waits at least half a second between pages on the same site, and only reads public pages. It never logs in or bypasses blocks. Links that another site refuses to let a bot check (403, 429 and similar) are counted as unverifiedLinkCount, not reported as broken. It records page-level SEO facts only: no personal data, emails or phone numbers. Pages are read as HTML without running JavaScript, so content added only by scripts is not seen.
