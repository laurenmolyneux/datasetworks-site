How to use

  1. Add Keywords (e.g. software, cleaning, solar) or leave empty for everything.
  2. Pick Notice kind: open opportunities you can bid on, contract awards (who won), or both.
  3. Optionally narrow by Buyer countries (DE, FR, GB...), CPV codes (72 = IT services, 45 = construction) and Minimum value.
  4. Run, then export as CSV, Excel or JSON. Schedule it daily with Published in the last N days = 1 for a daily tender alert.

FAQ

Is this a TED API alternative? It uses the official TED search API under the hood and adds UK Find a Tender and Contracts Finder, so you get EU and UK notices with one set of field names and no API code to write.

Do I need an API key for TED or Find a Tender? No. The official APIs are open; you only need an Apify account.

How do I get daily tender alerts by email or Slack? Save your input as a task, schedule it daily with Published in the last N days = 1, and add an Apify integration (email, Slack, Google Sheets, Zapier or Make) to send each day's new notices.

What is a CPV code? The EU's Common Procurement Vocabulary: an 8-digit code for what is being bought. Use the first 2 digits for a whole sector, e.g. 72 IT services, 45 construction, 79 business services, 33 medical equipment, 90 cleaning and waste.

Can I use it with ChatGPT, Claude or Cursor? Yes. Add the Apify MCP server with this tool (https://mcp.apify.com/?tools=datasetworks/public-tenders) and ask in plain English, for example "find open UK tenders for school catering this week".

Does it cover other countries? TED covers all EU member states plus EEA and some partner countries. Tell us which national portal you need next.

Data and responsibility

All data comes from official open-data APIs: the TED search API of the EU Publications Office (free reuse, including commercial) and the UK Cabinet Office's Find a Tender and Contracts Finder OCDS APIs (Open Government Licence v3.0). The tool does not return personal data: contact names, email addresses and phone numbers in notices are left out, and awarded suppliers are only listed when they are clearly organisations. TED keyword search covers the full notice text; titles are in the notice's original language, with TED's English summary line in titleEnglish.
