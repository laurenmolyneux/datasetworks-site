FAQ

Do I need an API key? No. All three registers have open APIs; you only need an Apify account.

Which industry codes do I use? Each register's own: France NAF (e.g. 62.01Z), Norway SN2025 with a dot (e.g. 62.100), Finland TOL 2008 (e.g. 62100). You can mix them in one run; each code is only sent to the register whose format it matches.

Does the date filter work for France? The French API has no registration-date filter, so the tool checks creation dates itself on a limited number of result pages. Combine it with an industry code or postcode for complete French results.

Do you return directors or owners? No. This tool returns company-level data only (see below).

Can I use it with ChatGPT, Claude or Cursor? Yes. Add the Apify MCP server with this tool (https://mcp.apify.com/?tools=datasetworks/european-company-registry) and ask in plain English.

Data and responsibility

Data comes from official open-data APIs: France's API Recherche d'entreprises (INSEE SIRENE and INPI RNE data, Licence Ouverte), Norway's Brønnøysund Enhetsregisteret (Norwegian Licence for Open Government Data, NLOD) and Finland's PRH open data (YTJ, CC BY 4.0; source: Finnish Patent and Registration Office). This tool is not affiliated with or endorsed by these agencies.

No personal data: directors, owners, beneficial owners, email addresses and phone numbers are never returned, and sole traders (whose company name is usually a person's name) are skipped. French records whose owner has not made them public are skipped. marketingOptOut: true means the French company has opted out of commercial prospecting: do not use those records for direct marketing.
