Extract text from Word, Excel and PowerPoint files for AI

Not every useful document is a PDF. Government statistics come as spreadsheets, tender packs come as Word files, investor updates come as slide decks, and long guides come as e-books. An AI agent or a RAG pipeline needs all of them as plain text.

What you get

PDF, Word, Excel & PowerPoint to Text takes links to files and detects the format from the file itself, so a link without an extension still works. Each result has a format field (pdf, docx, pptx, xlsx, odt, ods, odp or epub) and the text, plus title, subject, createdAt and modifiedAt where the file has them.

  • Word and ODT: paragraphs in order, with tables as tab-separated rows.
  • PowerPoint and ODP: text slide by slide, plus speaker notes for PPTX.
  • Excel and ODS: each sheet as tab-separated rows under a ## Sheet name heading.
  • EPUB: chapters in reading order.

Turn on per-page text and you get a pages list with one entry per PDF page, slide, sheet or chapter (sheets carry their name), so an answer can say where it came from. Set a chunk size to get chunks ready for an embedding step.

Steps

  1. Open the tool on Apify and paste your file links into Document URLs. You can mix PDFs, spreadsheets and slide decks in one run.
  2. Optional: set Max characters per file to fit your model's context, or Max pages per file to read only the first few slides or sheets.
  3. Run it and export as JSON, CSV or Excel, or call it from the Apify API or MCP server.

Cost

$0.003 per file read, whatever the format and however many pages, slides or sheets it has. No start fee. Files that fail, are blocked by robots.txt or are in an old binary format (.doc, .xls, .ppt) are free.

Good to know

Spreadsheets return the values saved in the file, not the formulas. Images inside documents are not read (no OCR). The tool never returns author, creator or last-modified-by fields, and it skips comments in OpenDocument files.
