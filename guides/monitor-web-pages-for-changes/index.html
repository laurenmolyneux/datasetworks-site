Monitor web pages for changes and get only what changed

Plenty of the pages that matter to a business have no feed and no alerts: a competitor's pricing page, a supplier's terms, a product's documentation, a regulator's notices page. The usual answer is to check them by hand, or to diff raw HTML and drown in noise from ads, menus and timestamps.

The Web Page to Markdown tool has a monitor mode that compares only each page's main text, so you hear about real content changes and nothing else.

Common uses

Competitor pricing and plans. Get told when a rival changes a price, renames a plan or adds a feature to a tier.

Terms, policies and legal pages. Track changes to suppliers' and platforms' terms of service, privacy policies and API terms.

Documentation and changelogs. Watch the docs your product depends on for new limits, deprecations or breaking changes.

Public notices. Follow notice boards, consultation pages and tender pages that are only published as plain web pages.

How to set it up

  1. Open the tool on the Apify Store and paste the pages you want to watch into URLs.
  2. Turn on Only return new or changed pages (monitor mode).
  3. Give the job a Monitor name, such as competitor-pricing, so different jobs keep separate memory.
  4. Save the input as a task and add a schedule (for example, daily at 8am).

The first run returns every page with changeStatus: "new". After that, each run returns only pages whose text changed, with changeStatus: "changed", the time of the previous check, and up to 50 addedLines and removedLines. Pages that did not change are left out and are not charged.

Example input for an AI agent or the API:

{
  "startUrls": [{ "url": "https://example.com/pricing" }],
  "onlyChanged": true,
  "monitorKey": "competitor-pricing",
  "outputFormats": ["text"]
}

Cutting out noise

Lines such as "5 minutes ago" are ignored by default, so live timestamps on news and status pages don't count as changes. If a page has other moving parts, such as a visitor counter or a rotating quote, set Ignore lines matching to a regular expression that matches those lines.

What it costs

$1 per 1,000 pages converted. In monitor mode you pay only for new and changed pages, so watching 50 pages daily where a few change each week costs a few cents a month.

Good manners built in

The tool reads only public pages, follows robots.txt and crawl delays, identifies itself honestly, and never logs in or gets around blocks. Pages that need JavaScript to show their content may return little text.
